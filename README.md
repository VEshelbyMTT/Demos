# Teaching Demos

A collection of practical demos used while teaching data engineering, data science, analytics, and cloud platform courses.

## Browse by subject

- `DP-100` contains supporting material for Azure data science training.
- `DP-203` contains data engineering demonstrations and pipeline examples.
- `databricks` contains data engineering, analytics, and data science examples.
- `dp600` contains Microsoft Fabric analytics exercises and training output.

## Using this repository

Start with the README or setup material inside the relevant folder. The examples were created for instructor led demonstrations, so some require a course environment, cloud subscription, sample data, or services that are not included here.

Course identifiers, interfaces, and prerequisites change over time. Treat these files as teaching examples rather than current production reference implementations.

This repository may contain my demonstration code alongside outputs or supporting files from official course exercises. Ownership and licensing can differ by folder. Refer to the source course and any notices included with the material before reusing it.
